# Murmur - playable web build

Play on iPhone: open the page link in Safari, then Share > Add to Home Screen for a full-screen view.

Current build: `b6fc42e` (2026-11-03). The same number shows at the bottom-left of the game.

| Item | Detail |
|---|---|
| Flocking | Locked to prototype v6 |
| Haptics | Not on iPhone Safari (Android build only) |
| Sound | Starts after your first tap |
| Benchmark and frame readout | In the start card, work in the browser too |

Feedback goes to the studio; accepted changes are made in the private source and carried to the Android build.
